How it's built

CloudFile Processor is a cloud-native system: a Java and Spring Boot backend running on AWS, plus this Angular web app.

Architecture

  • Direct uploads. The browser sends files straight to Amazon S3 using short-lived pre-signed URLs, so files never pass through the API.
  • Asynchronous processing. Upload events feed an Amazon SQS queue, and a worker service on ECS Fargate processes each file, with retries and a dead-letter queue for failures.
  • Metadata in DynamoDB, with a full status lifecycle: Pending, Processing, Completed, Failed and Deleted.
  • Authentication with Amazon Cognito (OpenID Connect, Authorization Code with PKCE). The API validates the JWT, and every query is scoped to the signed-in user.
  • Infrastructure as code with AWS CloudFormation, deployed through GitHub Actions.
